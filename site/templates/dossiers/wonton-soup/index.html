Take away a move.
Can the proof still be found?

A theorem can have several proofs. We let a search find one, block a tactic it used, and try again. Some searches find another route. Others reveal a dependency they cannot escape.

Resilience

A lesioned run still solves. The search reaches the goal within its budget.

Reroute

The lesion solves but lands in a different proof family or shows graph distance. The change is structural.

Rescue

The baseline fails but the damaged run solves. Removing a move can change which branches receive the search budget.

Count the routes that remain usable

Different-looking proofs can depend on the same indispensable tactic. Blocking a move asks whether the alternatives remain available under pressure. A successful rerun shows a route the search could still reach within its budget; a failure identifies a limit of that search.
