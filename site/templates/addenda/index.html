A pattern that feeds back on itself

A Julia implementation joins diffusion, a peak-counting gene network, and feedback using Catlab wiring diagrams and polynomial interfaces. In a 20-cell example, the cut with the largest measured pattern change ranks first by outcome-based severity and twelfth by a connectivity heuristic. Computing the severity ranking already requires simulating the outcomes; these positions are not a comparison of total prediction costs.

How much search does a policy save?

K compares the expected costs of an agent and a blind policy in the same problem space. This reference implementation makes the comparison executable: the moves, constraints, goal, horizon, and cost units stay fixed while the policy changes.
