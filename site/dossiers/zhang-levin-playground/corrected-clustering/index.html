Moving a waiting rule moves the clustering in self-sorting arrays

Cells of one type gather while a mixed array sorts because they move later than the others, and giving another sorting rule Insertion’s waiting gate brings the same clustering with it.

Zhang, Goldstein and Levin [1][1]T. Zhang, A. Goldstein, and M. Levin, “Classical sorting algorithms as a model of morphogenesis: Self-sorting arrays reveal unexpected competencies in a minimal model of basal intelligence,” Adaptive Behavior, 2024, Available: https://arxiv.org/abs/2401.05375 let every element of an array run its own sorting rule and found that elements running the same rule gather into runs while the array sorts, which they explained by some rules moving into place earlier than others and turned into a prediction of tissue islands in chimeric organisms. We test that explanation by moving the part of Insertion sort that sets its timing, a gate that makes each cell wait until everything to its left is in order. Given that gate, Bubble sort clusters nearly as much as Insertion does with the same number of swaps, and Insertion without it clusters no more than chance. Scored against shuffles of each run’s own type labels, the clustering in the original chimeras reproduces at the original array size and sits 0.07 to 0.12 above that null. With repeated values, clustering survives into the sorted array only in pairs that contain Selection, because the adjacent-swap rules never reorder equal values. With frozen cells, the rule that reroutes around a frozen target carries the model’s robustness to damage, while threaded and sequential execution do the same work. Timing decides where transient islands form, and only cells that exchange places with equivalents keep them.

1The model and what the original paper claims

In the original model each of 100 cells holds a value and runs one of three rules, which the paper calls algotypes. A Bubble cell looks at a randomly chosen neighbour and swaps with it if the pair is out of order, an Insertion cell moves left past a larger neighbour only once every cell to its left is in order, and a Selection cell keeps a pointer to the position it believes it belongs in, starting at the left end, and swaps directly with whatever cell sits there if that cell holds a larger value, advancing the pointer otherwise. Every cell is a thread, all threads share a single lock, so one cell acts at a time and the operating system decides which. The paper measures clustering with an aggregation value, the fraction of cells whose neighbour runs the same rule (p. 10), which we write as C. The original code divides the count of matching right-hand neighbours by all 100 cells, so the last cell always scores zero and a random arrangement averages 0.49, while we divide by the 99 adjacent pairs, which puts the random level at 49/99, close to one half, and raises every value by a factor of 100/99.

In chimeric arrays the paper reports that C rises while the array sorts and falls back as sorting completes, peaking at 0.72 for Bubble with Selection, 0.65 for Bubble with Insertion, 0.69 for Selection with Insertion and 0.62 for all three, at 42, 21, 19 and 22 percent of the way through the sort (p. 14). As a negative control it ran pairs of identical rules under two labels and found peaks of 0.61, 0.65 and 0.57 (p. 13), while the caption of Figure 8 describes the plotted control curves as showing no significant deviation from 50% chance and the plotted chimeric curves as peaking at 60% (pp. 33 to 34). To explain the chimeric peaks the authors proposed an efficiency hypothesis, in which cells with a more efficient rule reach their places first and the others catch up later (p. 14). With repeated values (each of ten values held by ten cells) clustering persisted to the end, with final values of 0.65 for Bubble with Selection and 0.7 for Insertion with Selection, which the authors took as support for the efficiency hypothesis because Selection is the more efficient rule (p. 14). Two further claims bear on this report: cell-view sorting accumulates less monotonicity error than the traditional algorithms when some cells are frozen (p. 11), and the clustering result suggests that a chimeric biological body will form tissue-level islands (p. 18).

We test the efficiency hypothesis by changing when a rule moves while leaving how it moves alone. InsertionNoWait is Insertion without its waiting gate, DelayedBubble and DelayedGnome carry the same gate inside Bubble and inside Gnome (a deterministic adjacent-swap rule), and BubbleClone and GnomeClone are ungated copies that differ from their partner only by name, so that pairing a rule with its clone makes a chimera in label alone. Every clustering result is scored against a shuffle null. For each sorting run the sequence of arrangements is held fixed, the type labels are shuffled among the cells 200 times, and peak C is recomputed for each shuffle; the excess is the observed peak minus the mean shuffled peak, and it asks whether cells of the same type move together more than arbitrary sets of cells of the same size do in the same run. Clustering curves are sampled after every swap, and frozen cells run no thread.

The original paper saw like cells gather while the array sorts and put the gathering down to timing. Our experiments ask whether changing a rule’s timing, and nothing else, moves the gathering with it.

2Chimeric clustering reproduces at the original size when scored against shuffled labels

At the original size of 100 distinct values, mixing two rules makes like cells gather more than chance, and two copies of one rule under different labels do not. We checked this with our own sequential reimplementation of the three rules, in which a uniformly chosen cell acts at each step, with 40 runs per pair and 200 label shuffles per run. Pairs of identical rules peak between 0.57 and 0.62, within the original control range of 0.57 to 0.65, and each peak lies within 0.01 of its own shuffle null, so the original control level is what the maximum of a noisy curve gives when type has no effect. The three chimeras peak at roughly the original heights and times and lie 0.07 to 0.12 above their nulls. The original comparison of chimeras with identical-rule controls was therefore the right comparison and its conclusion stands.

The caption of the original Figure 8 is also right about what it plots, since a curve averaged over runs at each point of progress stays near one half whenever the labels carry no information (our identical-rule mean curves peak at 0.509 to 0.519, our chimeric mean curves at 0.604 to 0.666, against the caption’s 60%). The peaks quoted in the text behave like the mean over runs of each run’s own maximum, which is the statistic in the table below. We infer this from the match: our identical-rule values fall inside the original control range and our chimeric values sit near the text’s 0.65 to 0.72, while the maximum of a mean control curve, which is what the original plotting code prints, stays near 0.51 to 0.52 in our runs, well below 0.57. What needs correcting is the reference level, because a chimeric peak of this kind has to be read against a per-run-peak null of 0.56 to 0.62, as the text on pp. 13 and 14 does.

3Clustering follows the timing of each type’s moves

Clustering tracks separation, a measure of when each type does its moving. Each swap gets its position in the run, scaled from 0 to 1, each type gets the mean position of its own cells’ swaps, and separation is the absolute difference between the two types’ means, which is near zero when the types act interleaved and grows when one type does its moving earlier. Across ten pairs at 30 cells, drawn from Bubble, Selection, Insertion, Gnome and Shaker (a rule that alternates between checking its right and its left neighbour), the four pairs containing Insertion separate by 0.12 to 0.21 and cluster 0.05 to 0.09 above their nulls, while the six other pairs separate by only 0.04 to 0.05 and cluster between 0.00 and 0.03 above theirs. The correlation of 0.94 across all ten pairs is therefore mostly the gap between those two families. Within the six pairs without Insertion it is 0.43, and the three Selection pairs among them cluster 0.026 to 0.031 above their nulls at separations of 0.04 to 0.05, about the same as Bubble with Gnome (0.043), which does not cluster at all.

Moving the gate moves the clustering. Removing Insertion’s gate brings Bubble with InsertionNoWait from an excess of 0.079 down to −0.007, which is the null: its raw peak still sits 0.131 above one half, but the shuffle null for that pair already sits 0.137 above it. Moving the gate into Bubble raises the excess from 0.017 for an ungated clone to 0.064, close to the 0.061 that Bubble with Insertion reaches in the same experiment, and moving it into Gnome raises it from 0.006 to 0.052. Every adjacent-swap rule makes exactly one swap per out-of-order pair, so the gated and ungated Bubble runs do the same expected amount of work (612 and 616 swaps on average), and the gate changes only when each type does it. In each gated pair only one run in five clears its own shuffle test at the 5% level, so the excess is detectable in the mean over runs and weak in any single run.

Delaying a type’s moves is enough to make it gather: a rule with Insertion’s wait added clusters, and Insertion with the wait removed does not. The effect shows in the average over many runs rather than in any one run, and the Selection pairs cluster a little without any delay, so in this set of rules timing is the main cause of clustering but not the only one.

4With repeated values, clustering persists only in pairs that contain Selection

We repeated the original duplicate-value experiment at its own size, 100 cells holding the values 1 to 10 ten times each, with 40 runs per pair. Insertion with Selection ends at 0.703 and Bubble with Selection at 0.690, close to the original 0.7 for the first and above the original final 0.65 for the second and near the original’s 0.69 maximum, and both lie about 0.2 above the shuffle null for the final arrangement. Bubble with Insertion peaks at 0.659 after 17% of the sort, as the original’s 0.63 at 13% did, and then returns to the null. Bubble with DelayedBubble follows the same curve as Bubble with Insertion, and Bubble with InsertionNoWait does not rise above its null at any point.

The final rows of the adjacent-swap pairs are identical because those runs end in identical arrangements. Bubble, Insertion and their variants only swap neighbours that are strictly out of order, so two cells holding the same value never pass each other, and in every one of their runs each group of equal values ends in the order it started in, after exactly as many swaps as the starting shuffle has out-of-order pairs (2,259 on average). The sorted arrangement is then fixed by the starting shuffle, which ignores type, and the final C of any pair of adjacent-swap rules lands at the null whatever the rules’ timing. Selection’s long-range swaps carry a cell past others holding its value, no Selection-containing run kept equal values in their starting order, and in both pairs that mix Selection with another rule the final share of cells beside a same-type neighbour ends about 0.2 above the shuffles.

Timing makes islands that dissolve once the array is sorted. Only a rule that lets a cell jump past its equals can leave islands in the finished array, so the persistent clustering the original paper read as support for the efficiency hypothesis comes from Selection’s long jumps.

5Rerouting around a frozen target carries the robustness to damage

Threaded and sequential execution of the same rules do the same work once frozen cells run no thread, with active-cell comparison counts within about 3% of each other in every condition (ratios 0.97 to 1.02) and identical success counts, as expected from a single shared lock that makes the threaded version a random sequential scheduler. Neither Bubble nor Insertion reached a sorted array in any of the nine runs in either mode, so their ratios compare runs stopped at the time limit.

The factorization experiment (30 cells) crosses the reach of Selection’s swaps, long-range or adjacent only, with its response to a frozen target, rerouting to the next position or waiting on it. When frozen cells cannot be moved at all, only long-range rerouting sorts the active cells, in all 30 runs at 3, 6 and 9 frozen cells, with fewer swaps as fewer cells take part (108 without frozen cells, 56 with nine). Long-range waiting stalls as soon as its target is frozen, and the adjacent variants can never carry a cell across a frozen one, so the target order is out of reach and they keep swapping until the 5 s time limit (on average 14,077 swaps for adjacent rerouting and 6,831 for adjacent waiting with three frozen cells, against 412 and 404 without). Under the original default, in which frozen cells cannot initiate swaps but can be moved by active neighbours, long-range rerouting sorts 3 of 15 runs with one frozen cell and none with two or three, and every other variant fails whenever a cell is frozen. Since these outcomes follow almost directly from the rules, they are best read as consistency checks of the implementation. The state-space measure K for long-range rerouting falls from 30.45 to 18.01 as frozen cells go from 0 to 9, staying 1.7 to 2.0 below the base-10 logarithm of the number of arrangements of the active cells, so its decline tracks the shrinking number of arrangements of the active cells. The dip statistics reproduce (Bubble dips in every run, 34.8 times on average, Selection in 98% of runs, 3.7 times), but they still lack a random-walk null.

A cell whose target is frozen either waits, and the sort stalls, or moves on to the next position, and the sort finishes. That choice decides whether the array survives damage, and running the cells as threads changes nothing about it.

6Four untested conjectures about mechanism

Everything in this section goes beyond the measurements above. Each conjecture names the result that would count against it, and none of the four has been tested yet.

6.1Transient clustering comes from types acting at different phases of the sort

The gate transplant turns the original efficiency hypothesis into an intervention result, since adding Insertion’s wait to Bubble produces nearly the full Insertion-level clustering with the same total work, while the ungated clone stays at the null. We read this as heterochrony in the developmental sense, where two cell populations following one global goal but working on different schedules leave temporary territories behind, and where the territory reflects when a population acts rather than how much it does. If that is right, clustering should rise smoothly with the strength of the gate (for instance a gate that waits for only the nearest k cells to its left to be sorted), and the size of the excess should be predictable from separation within a family of rules as well as between families. A graded gate that raises separation to the Insertion level without raising the excess, or one whose excess jumps without a matching change in separation, would show that timing alone does not carry the effect.

6.2Persistent clustering needs a rule that reorders equivalent cells

The duplicate-value runs separate two things that the original reading kept together. Timing differences exist in Bubble with Insertion and leave no trace in the final arrangement, because both rules are stable sorts and the order among equal values is decided once, by the starting shuffle. Selection is unstable and decides that order dynamically, by which cell claims a position first. A chimeric body may face the same distinction: cells that share a positional target can either keep their neighbour relations while moving or exchange places with equivalents, and only the second kind of movement can let type-specific timing write itself into the final pattern. The conjecture predicts that Selection restricted to adjacent swaps (the adjacent-rerouting variant of the factorization experiment) leaves no final excess in a chimera with repeated values, and that a long-range rule made stable, one that never jumps past an equal value, also leaves none. Final clustering above the null in either case would break it. The Selection pairs also cluster more with size, with Bubble with Selection rising from 0.026 at 30 cells to 0.052 at 50 and 0.073 at 100 while Bubble with Insertion stays between 0.06 and 0.08, which fits a mechanism tied to the length of Selection’s jumps. Those three sizes come from two implementations, though, and a single implementation at 200 cells in which Bubble with Selection does not exceed its 100-cell excess would weaken that reading.

6.3Frozen-cell robustness comes from rerouting, and the substrate question is open

With frozen cells running no thread, the threaded runs behave like a random sequential scheduler, which is what a single shared lock makes them, so the experiments so far cannot say whether a truly distributed substrate changes anything. What does change outcomes is the rule for a blocked target. Long-range rerouting is a small, explicit form of the problem-solving the Levin program studies, a cell that reaches the same goal by a different path when its usual path is blocked, and it is the one variant that keeps sorting as the frozen fraction grows. Our bet is that a lock-free implementation, in which cells read stale neighbour values and conflicting swaps can collide, will still let long-range rerouting sort while the adjacent variants degrade further, and that the original advantage of cell-view over traditional sorting with frozen cells comes from the traditional baselines lacking rerouting. A lock-free run in which adjacent rules recover, or one in which long-range rerouting loses its advantage, would count against it.

6.4The islands prediction can be scored now

The prediction that a chimeric body will form tissue-level islands (p. 18) becomes testable in the model once each run is compared with shuffles of its own labels, and the results above give two versions of it. Islands that form during rearrangement and dissolve should appear whenever two cell types differ in when they move, and islands that persist should need the types to share positional targets and at least one of them to move past equivalent cells. In a chimeric worm or a mixed-cell aggregate, the second version predicts that persistent islands go with exchanges among cells of equivalent positional identity, and observing persistent islands where such exchanges can be ruled out would show that the sorting model is missing a mechanism the tissue uses.

Taken together, the four conjectures say that the model’s islands come from schedules and from exchanges between equivalent cells, and each one names an experiment that could show otherwise.

7Original claims not yet retested

Several original experiments remain without a corrected counterpart: the opposite-direction chimeras and their incompletely sorted equilibrium, the three-type mixture, the efficiency comparisons between cell-view and traditional sorting, and the rise in delayed gratification with the number of frozen cells, which the original uses to argue that the behaviour is not a random walk. That last trend needs the same kind of null as the clustering, and the dip statistics need a random-walk null before they can support it. The original also describes the algorithms as deterministic (p. 16), while Bubble chooses its neighbour at random and the operating system orders the threads, so seeded threaded runs do not repeat exactly.

Until these are redone, the original claims about efficiency and about dips rising with damage stand as the paper reports them, without an independent check.

8Timing makes the islands and exchange keeps them

The self-sorting array is a small model organism with a rulebook we can read in full, and the principle of organization it shows here is a schedule. Cells of one type gather because they move at a different time from their neighbours, and moving the waiting rule from one sorting rule to another moves the gathering with it, which makes the gate an intervention handle on the pattern. What the finished array remembers of that history depends on whether cells can trade places with their equivalents: adjacent-swap rules erase it and Selection’s long jumps write it into the final pattern, so the hidden variation that decides the outcome is the order among equal cells. In the lesion test, whether the array keeps its future under damage comes down to one rule, rerouting around a frozen target, and not to the threaded substrate. The space of patterns this opens is small and structured: graded gates, stable long-range rules and lock-free schedules each predict where islands should form and whether they should last.

A.1What our earlier version got wrong

The earlier follow-up by Pouey and Rohr reran the original rules from byte-identical copies of the upstream cell classes and introduced the gate ablation and transplant, the factorization of Selection’s frozen-cell robustness into the reach of its swaps and its rerouting, and the comparison of threaded with sequential execution. Rechecking it found four problems that changed numbers. Clustering was scored as peak C minus one half, and a maximum taken over hundreds of noisy snapshots sits well above one half even when type has no effect, so most of each reported increase was null; the earlier description of the InsertionNoWait drop as a sharp reduction understated it, because without a null the remaining raw value of 0.091 looked like residual clustering. Figure 2 sampled C every 0.02 seconds of wall-clock time, which gave the slower gated runs more samples and therefore higher maxima. The threaded runs in the work comparison started threads for frozen cells, which the original’s multithread_cell_sorting_with_frozen_steps.py does not do, although its freezing_sorting_analysis.py does, and a frozen Selection thread keeps counting comparisons without moving. The result files behind the figures had not been committed.

A.3Independent checks

sim.py reimplements Bubble, Insertion, Selection, InsertionNoWait, DelayedBubble and Gnome sequentially, with a uniformly chosen cell acting at each step and C recorded after every swap. null_n100.py runs 40 runs per pair at 100 distinct values (run seeds 5000 + t, shuffle seeds t) and duplicates_n100.py 40 runs per pair at values 1 to 10 repeated (run seeds 7000 + t); both use 200 label shuffles per run, and the duplicate check also scores the final arrangement against its shuffles and tests whether each group of equal values keeps its starting order. run_cluster.py is the earlier 50-cell check (excess 0.052 for Bubble with Selection, 0.075 for Bubble with Insertion). Intervals are mean ± 1.96 standard errors over runs. In the duplicate runs, Bubble with Bubble peaks 0.011 above its null (0.003 to 0.020), a small residual we have not explained. Run null_n100.py and duplicates_n100.py with uv run --no-project --with numpy==2.1.3 python <script> <out.json>, and run_cluster.py with uv run --no-project --with numpy==2.1.3 --with scipy python run_cluster.py <directory holding sim.py> <out.json>.
