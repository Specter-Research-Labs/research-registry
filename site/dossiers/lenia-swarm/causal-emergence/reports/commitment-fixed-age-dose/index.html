An Intervention That Works Early Stops Working Four Steps Later

One early push genuinely narrows the future. Replaying the same push does not deepen that state—it moves the organism somewhere else.

The surprising result is not that control failed. Control was abundant. What expired was the direction of control: as the system developed, yesterday’s commitment-increasing action stopped pointing toward commitment.

01 · THE TEST

Same ancestor. Same action. Different moments.

At passage 32 we gave each organism one of eight inventory-preserving pushes. At passage 36 we identified a high-commitment and low-commitment sibling. Then we either stopped, repeated the same push once, or repeated it three more times. All dose histories were finally compared at the same passage 56 age and challenged with the same eight actions.

03 · CAUSAL ANATOMY

The second pulse helps the low branch catch up.

Dose-1 and dose-2 histories are identical through passage 36. The only difference is the repeated action at passage 37. Its effect at passage 40 is strongly asymmetric.

This changes the picture. Commitment is not a static substance we can keep adding. It is a transient relation between the organism’s present state and the actions available from that state.

NEXT DIRECT SWING

Let the controller re-read the organism.

Open-loop replay

Choose an action at passage 33 and repeat that same action at passage 37, passage 41, and passage 45. We now know this moves the field but loses the intended direction.

Adaptive re-selection

At every pulse, re-probe all eight actions from the organism’s current state and choose the action that points toward the current commitment direction. Compare both at passage 56 under the same challenge repertoire.

If adaptive control preserves the split while replay does not, we have demonstrated a rotating information-geometric control field over development.
