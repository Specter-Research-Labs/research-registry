Early Histories Already Shape Later Responses

Nearly thirty passages before the certified formation transition, the system already has a mature, history-dependent map of possible futures.
We moved the same score-matched intervention geometry backward through five developmental states. The future map was full-size at the earliest state. What changed later was the body: morphology folded more deeply while timing plasticity contracted.
The result

Development begins with causal multiplicity.

The future landscape is already separated. The visible state catches up to it.

Curve one · causal future

The action world starts high and stays high.

Each point is the distance between futures reached through different histories while final Φ‑R is held approximately fixed. The curve is flat from 28.5 passages before formation through the crossing itself.

None of the first two eight-passage transitions changes the future displacement detectably. The only clear adjacent change is a small decline approaching the near-event state: -0.007, 95% interval -0.012 to -0.001.

Curve two · visible state

Morphology progressively folds around that map.

The same matched-history distance measured directly in the release state grows at every developmental step. From earliest state to crossing it rises by 21.0%.

Interpretation

Development writes an existing causal multiplicity into increasingly distinct bodies.

Curve three · plasticity

The early system has more freedom over when it forms.

At the earliest window, four information-directed histories spread the same later morphology event across almost six passages. By the crossing state that range has fallen to about three—a 50% contraction.

The route direction is not universally “faster” or “slower”; it depends on organism, ending level, and local state. The stable phenomenon is broader timing leverage early and narrower leverage near commitment.

One untouched developmental sequence

The visible change is gradual.

This organism's certified transition is passage 56. The five images span the exact interval analyzed. Nothing in the first image announces that its intervention-response map is already as separated as it will be near passage 56.

One primordial score sheet

Four near-matched presents.

At passage 24—32 passages before this organism's certified event—the four history-conditioned states are hard to distinguish by eye. The median matching gap across the cohort is only 1.64% of the local Φ‑R range.

The same challenge, much later

Four visibly different futures.

Apply the same c04 intervention after release and follow each state to passage 900. The small-looking early differences reorganize the later form. Across the cohort, the history displacement is roughly one full local repertoire width.

The developmental principle

Commitment is a transfer of structure.

early: wide causal choice + shallow visible fold
later: stable future map + deeper body fold + narrower timing freedom

The system does not acquire a future map when it becomes visibly organized. It begins with multiple history-dependent futures, then progressively converts that hidden organization into morphology while losing freedom over the timing of formation.

A useful name for this is causal-first development: causal response structure leads; visible form consolidates it.

The next direct swing

Was the future map inherited—or self-assembled?

We still have not found its beginning. The earliest relative window was already too late. The next experiment goes to fixed absolute ages: the first possible two-pulse sheet, then passage 8, passage 16, passage 24, and passage 32. That will tell us whether the action world is present almost immediately after initialization or rises during the ecology's earliest self-organization.

If it is immediate, we compare against scrambled/spatially rearranged founder controls. If it rises, we intervene at the rise and ask whether redirecting it changes which form later consolidates.
