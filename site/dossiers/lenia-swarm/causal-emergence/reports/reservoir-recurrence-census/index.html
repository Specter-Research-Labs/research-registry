Reservoir Recurrence Was Too Sparse to Test the Score

We found genuine episodes where a four-founder mixture returned after repeated passage and regrowth. But this census did not produce the fair positive-versus-negative comparison needed to ask whether an early whole-system information signal foretold them.

That distinction matters: Φ did not fail. It was never calculated on this cohort.

02 / The event

What “comes back” means here.

This is not ordinary Lenia fission. We impose a GARD-like cycle on the ecology and follow composition, not silhouette.

qR

Threshold return

A small external founder parcel is added; Flow Lenia regrows until the passage threshold is crossed again.

One window = four cycles

A single lucky recovery is not enough. We slide a four-cycle window through every run and ask whether the mixture repeatedly returns.

A window passes only if…

  • the passage meaningfully disturbed the mixture;
  • the return stayed close to the parent every time;
  • the median return was at least 0.95 similar;
  • at least three of four cycles improved over the daughter.

Strict positive: an informative failure in the prefix, followed by a passing window wholly in the future. Strict negative: an informative prefix failure, no later pass, and at least two informative future failures. An early pass, a cutoff-crossing pass, or too little evidence stays unlabelled.

No Φ value exists for this census.

Had the gate passed, the next stage would have used only the prefix to estimate how much the whole four-founder state predicts its next state beyond its best split into parts.

ΦR = information in the whole − information in the best-separated parts

We would then ask whether ΦR predicts later recurrence beyond mass, recent growth, fragmentation, motion, component count, and other plain controls. That test was not run, because its outcome comparison was not identified.

08 / Meaning

What we learned—and what we did not.

This is a useful intermediate result: the phenotype exists, while the current sampling design does not identify its precursor.

We can say

  • The reservoir passage operator worked mechanically in all 72 trajectories.
  • Reservoir-fed founder-composition recurrence genuinely occurred: 56 passing windows across 22 runs.
  • Four runs showed a strict transition from prefix failure to future recurrence.
  • This cohort cannot support a clean whole-versus-parts precursor comparison.

We cannot say

  • Integrated predictive information rose before recurrence.
  • Integrated predictive information failed to predict recurrence.
  • Flow Lenia has—or lacks—causal emergence.
  • These systems autonomously reproduce, or that p31003 caused recurrence.

A different test would need new data: fix the contrast, not the answer.

  1. Use this census only to design a new, prospectively frozen outcome-yield study.
  2. Run more fresh schedules per family and a longer pre/future observation horizon, while keeping the recurrence thresholds unchanged for the first extension.
  3. Require repeated positives and negatives inside at least three families. Do not select only p31003, relabel grey runs, or loosen thresholds.
  4. Then freeze a separate fresh confirmation cohort and open the prefix-only Φ-versus-controls analysis exactly once.
  5. If a precursor survives confirmation, perturb it with no-op, random, mass-matched, and spatially matched controls before using causal language.

The arithmetic amendment, in plain English

The first analysis attempt stopped before producing any outcome labels. It had compared two totals accumulated in different—but both legitimate—Float32 orders: one global sum and four founder-bucket sums. Seven late events in one trajectory differed only because floating-point addition is order-sensitive.

The stage-local amendment did not widen a tolerance. It required the incoming founder identity vector to bit-match the recorded event, reconstructed the grouped mass through the exact same arithmetic path, and authorized only the already identified events. All 2,803 division events passed before outcomes were opened. No simulation state, recurrence threshold, history window, episode rule, label, or frozen input changed.

Independent outcome reconstruction

The saved mechanical audit was replayed from the raw artifacts. Every cycle, four-cycle episode, status, family count, and final decision reconstructed exactly: four later-recurrence labels, four no-later-recurrence labels, zero qualifying families, and stop_without_phi.

Final claim boundary: Outcome-only census of founder-composition recurrence across externally imposed growth-passage cycles; not autonomous reproduction, causal emergence, or Phi.
