A fresh causal return-loop experiment

Equal Scores Can Encode Different Histories

We drove 64 fresh Flow Lenia organisms away from an information-score regime and then back into it. The scalar returned; the state and its causal future retained the route.

The result

A one-dimensional score hid a two-dimensional history.

At passage 44, hold and excursion paths differed by only 3.0% of the score range on average—1.1% at the median. If this scalar described the causal state completely, the branches should have converged. They moved farther apart instead.

Memory through release

The hidden split grew monotonically.

The last intervention occurred at passage 41. From passage 44 through passage 64, there was no relaxation toward a common organism. Form-space separation increased at every fixed readout. The scalar score gap, initially tiny, reopened roughly ten-fold by passage 48 and continued growing.

The causal future

The whole future cloud stayed displaced.

At passage 49 and again at passage 57, each branch received the same eight challenge seeds plus free continuation. The repertoire did not shrink or expand much. It moved: matched endpoints after loop versus hold were separated by almost exactly one complete repertoire width at both times.

What this means

The scalar is not the causal state.

Two organisms can occupy nearly the same information-score coordinate while carrying different histories, different dynamics, and different maps of what happens next.

A causal phenotype

The result suggests treating an organism’s position in future-repertoire space as a phenotype in its own right. Width measures plasticity; position measures which possibilities are actually nearby.

The score is useful for steering, but it compresses multiple history-dependent causal states onto the same number. Development may be commitment by translation between those hidden sheets—not merely a scalar rising or falling.

The next experiments

Now we can hunt this before organism birth.

  • Continuous loopSweep through several matched score levels and trace an actual loop in causal-repertoire space. That would turn this return-memory result into a full hysteresis curve.
  • Open-loop replayReplay the exact chosen seed histories without feedback. This separates memory in the physical pulse sequence from memory created by state-dependent control.
  • Pre-birth scanMeasure repertoire position, not only Φ-like magnitude, before a body becomes coherent. A sudden translation may be the missing precursor to organism emergence.
  • Event couplingAsk whether repertoire jumps lead fission, identity turnover, ecological succession, or recovery—our direct bridge back to the Levin-style precursor question.
64 fresh organic ancestors · 128 matched return pairs · 256 release readouts · 4,352 untouched causal futures · 10,000 bootstrap resamples. High and low mirrors agree. The tightest 32 pairs had only 0.16% mean normalized return mismatch yet retained passage 44/passage 64 state distances of 0.127/0.150 and immediate/delayed future shifts of 0.239/0.240. This demonstrates causal return memory at a matched scalar score; a continuously swept one-parameter loop remains the next strict hysteresis test.
